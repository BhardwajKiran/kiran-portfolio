# Kiran Bhardwaj — Portfolio

A responsive, dark editorial-style portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish for free with Vercel
1. Create a public GitHub repository named `kiran-portfolio`.
2. Upload all files and folders from this project.
3. Sign in to Vercel with GitHub and import the repository.
4. Keep the framework preset as Other; leave build command and output directory blank.
5. Deploy. Your site will receive a free `*.vercel.app` address.

## Before publishing
- Review your public resume PDF and decide whether you want your phone number visible.
- Check project repository links and add direct links/screenshots for the ShopKart project if available.
- Replace any project link if its exact repository differs.
