# Kiran Bhardwaj — Data Analyst Portfolio

A responsive, dark-premium portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — navigation and interactions
- `Kiran_Bhardwaj_Resume.pdf` — downloadable résumé

## Project media and content
ShopKart, Coffee Shop, Mobile Sales, and Bank Loan cards use actual images from the corresponding public project repositories. Adidas and SQL use clearly labeled document/code-style previews rather than fabricated dashboard screenshots. ShopKart uses synthetic data; its figures describe the project dataset, not a real business.

## Deploy with Vercel
Import this GitHub repository into Vercel, choose **Other** as the framework preset, and leave the build command empty. This is a static HTML/CSS/JS site. Keep the files in the repository root.
